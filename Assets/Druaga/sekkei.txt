CustomSequenceConditions説明
使用例（よくあるパターン）
パターン1: 「特定の方向を向いたまま数秒待つ」
C#// シーケンス例
sequenceSteps.Add(new SequenceStep 
{ 
    actionType = "FaceToward", 
    targetPos = new Vector2Int(5, 10), 
    description = "北を向く" 
});

sequenceSteps.Add(new SequenceStep 
{ 
    actionType = "Wait", 
    waitDuration = 3f, 
    description = "3秒待つ" 
});
→ 待機は FloorManager.Update() や別タイマーで管理し、一定時間経過したら OnActionPerformed("Wait") を呼ぶ必要があります。
パターン2: 「特定の場所を順番に通過する」
C#sequenceSteps.Add(new SequenceStep { actionType = "MoveTo", targetPos = new Vector2Int(3, 5), description = "A地点へ" });
sequenceSteps.Add(new SequenceStep { actionType = "MoveTo", targetPos = new Vector2Int(10, 2), description = "B地点へ" });
sequenceSteps.Add(new SequenceStep { actionType = "MoveTo", targetPos = new Vector2Int(7, 12), description = "C地点へ" });
パターン3: 「特定の敵を特定の順番で倒す」
C#sequenceSteps.Add(new SequenceStep { actionType = "Kill", targetEnemyId = "MageA", description = "最初の魔法使い" });
sequenceSteps.Add(new SequenceStep { actionType = "Kill", targetEnemyId = "KnightB", description = "次にナイト" });
連携方法（PlayerController / FloorManager）
C#// PlayerController.cs の移動処理内
if (movedToNewPos)
{
    foreach (var cond in FloorManager.Instance.GetConditionsOfType<CustomSequenceCondition>())
    {
        cond.OnActionPerformed("MoveTo", newGridPos);
    }
}

// 向きを変えたとき
if (facingChanged)
{
    foreach (var cond in FloorManager.Instance.GetConditionsOfType<CustomSequenceCondition>())
    {
        cond.OnActionPerformed("FaceToward", facingGridPos);
    }
}
注意点

複雑なシーケンス（例：レバー操作連打、特定の敵を連続で倒すなど）は
必要に応じて actionType を増やしたり、SequenceStep にパラメータを追加してください。
待機系（Wait）は現在の設計では直接対応が難しいので、
FloorManager にタイマー管理を追加するか、別の条件クラスと組み合わせるのが現実的です。

これで「非常に特殊な条件」にも柔軟に対応できます。
ドルアーガの塔では後半になるほどこの手の条件が増えるので、
最も汎用性の高い条件クラスの一つになります。
